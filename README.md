Derin Öğrenme Tabanlı Akustik Olay Algılama ve Sınıflandırma Sistemi Mart 2025
Mutfak güvenliği için pişirme süreçlerini gerçek zamanlı analiz eden yapay zeka tabanlı ses işleme sistemi
geliştirildi.
Mel-spektrogram verileri kullanılarak hibrit CRNN (CNN + LSTM) modeli tasarlandı.
RMS ve ZCR tabanlı sinyal işleme mekanizmaları ile hatalı algılamalar azaltıldı.
FastAPI ve React.js kullanılarak gerçek zamanlı analiz ve görselleştirme sağlayan web platformu
geliştirildi.
Ses işleme, olay sınıflandırma ve canlı veri analizi süreçleri optimize edildi.
Teknolojiler: Python, TensorFlow, Librosa, FastAPI, React.js, FFmpeg, Deep Learning
